# memPY
The spiritual succesor to memSafe

# How to use

To start, copy `memPY.py` into your project's folder\
Then use `from memPY import *` to import all functions\
To uses memPY you'll first want to set a memory size using `setSize(<num of slots>)`\
Then, to allocate memory, use `alloc(<slot>)`\
To set that slot to something use `mSet(<slot>,<value>)`\
To free it use `free(<slot>)`\
